# 🏢 Module: Department — Quản lý phòng ban

## Phạm vi nghiệp vụ
Module `department` quản lý cơ cấu tổ chức phòng ban:
- Danh sách phòng ban (CRUD)
- Cây phòng ban (cấp trên / cấp dưới)
- Gán nhân viên vào phòng ban
